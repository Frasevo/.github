# Frasevo

**Design visually. Build for the web. Own the result.**

Frasevo is a visual web-building platform in development. We're connecting the flexibility of a visual editor with the structure and control of modern web development, so creating a website doesn't mean giving up control of its code.

## What we're building

- **Visual editing** — create layouts, organize layers, and refine every detail directly on the canvas.
- **Responsive by design** — shape experiences across desktop, tablet, and mobile.
- **Reusable building blocks** — work with components, design styles, and assets across pages.
- **More than static pages** — bring content, forms, and integrations into the same workflow.
- **Code ownership** — export projects and continue developing or deploying them outside the editor.
- **Team workflows** — organize projects, review changes, and collaborate as they evolve.

Our goal is to make visual creation and professional web development part of one continuous process.

## Open-source work

Frasevo itself is being developed privately. We also publish selected independent developer tools that may be useful to the wider community:

- [Frasevo Code Intel](https://github.com/Frasevo/frasevo-code-intel) — offline, read-only tooling for source analysis, code navigation, and documentation traceability.

> **Project status:** Frasevo is under active development and is not yet publicly launched. Features and availability may change before release.
